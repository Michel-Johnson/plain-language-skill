# 说人话 Skill

用清楚、准确的语言撰写、解释、改写和审查技术内容。保留事实与技术细节，帮助读者理解结论、条件和下一步。

- [Skill 入口](skill/SKILL.md)：任务选择、表达流程和自检。
- [详细原则](skill/references/principles.md)：长文或技术密集内容按需读取。
- [可选检查脚本](skill/scripts/lint_plain_language.py)：提示表面表达风险，不判定读者是否理解。

安装时将 `skill/` 复制到客户端的 `plain-language/` Skill 目录。使用支持显式调用的客户端时，可以输入“使用 $plain-language 把这段内容讲清楚”。

本仓库只维护说人话 Skill。`history/` 是本地历史资料，不纳入 Git；当前版本以 `skill/` 为准。
